# CIFAR-10

Download: https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz

Or in the terminal:

```bash
wget https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz
```

Extract (creates `cifar-10-batches-py/`):

```bash
tar -xzf cifar-10-python.tar.gz
```

The extracted `cifar-10-batches-py/` folder is what the training/evaluation scripts use (default `--data-root ~/research/data`).
